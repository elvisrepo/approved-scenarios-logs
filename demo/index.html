      The three patterns
      
    
        
      
      • Constrained Tests — the parent. An external DSL + strict parser makes hollow tests impossible, so coverage means something. pattern page · local write-up: docs/constrained-tests-explained.md
        • 
      
      • Approved Scenarios — constrained tests optimized for review ease: input + expected output in domain language. pattern page · local write-up: docs/approved-scenarios-explained.md
        • 
      
      • Approved Logs — constrained tests optimized for bug-repro speed: production log sections become regression tests. pattern page
        • 
    
      
    
      Rule of the house (AGENTS.md): scenarios/ and logs/ are approved specification — propose, review, then write; the runner never fixes anything.
